# Roadmap

Items below are proposals, not completed features or dated commitments.

1. Validate the current pipeline against a permission-cleared real dataset and an independent calculation; document discrepancies.
2. Collect reproducible user feedback on input preparation and interpretation before broadening the interface.
3. Implement one instrument-export adapter with representative, shareable fixtures and clear version support.
4. Add explicit efficiency/multiple-reference support and appropriate validation fixtures.
5. Design repeated-measure and batch-aware analyses with independent statistical review.
6. Consider a local GUI and editable Prism export only after the schema and calculation contract are stable.

Keep issues and release notes based on work actually performed, and distinguish implemented features from proposals.
